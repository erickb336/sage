# Select guidance at the decision

Read this compact index at entry. Choose skills from the actual available catalog, then read their instructions before the relevant decision. In this plugin, principle skills are siblings of `sage`: `../principle-<name>/SKILL.md` relative to the sage directory. Writing skills include `writing-standard`, `dictionary` and `readme-guide`. Confirm the actual path before use.

| Decision or problem | Relevant principle skills |
| --- | --- |
| Product cases or experience | experience-first, exhaust-the-design-space |
| Data model and structure | foundational-thinking, model-the-domain |
| Validation and provider boundaries | boundary-discipline |
| Concurrent writes and retries | separate-before-serializing-shared-state, make-operations-idempotent |
| Refactor or API replacement | subtract-before-you-add, laziness-protocol, migrate-callers-then-delete-legacy-apis |
| Failure or repeated ineffective repair | fix-root-causes, attack-the-premise |
| Checks and evidence | test-behavior-not-implementation, prove-it-works, explain-the-number |
| Handoffs and reports | contextualize-and-write-for-the-reader, minimize-reader-load |
| Long or repeated work | sequence-verifiable-units, guard-the-context-window, encode-lessons-in-structure |

Match the decision, not a keyword. These are candidates, not mandatory reads of every skill. Use domain skills from the available catalog when the task calls for them. Read their exact instructions; do not infer them from the name.

The brief names selected skills and why they apply. A child reads them itself when context is not inherited. Reassess after a failure, new scope, review finding or recovery. Avoid repeated reads of unchanged material already in context. Selecting no additional principle is valid when none applies.

Describe application through the resulting decision or evidence, not a list of skills read. Loading, naming or quoting a skill proves delivery only. This workflow makes no claim that prompt-led selection outperforms hooks. Optional advice, comparative trials and paid experiments remain separate decisions.

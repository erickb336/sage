**Approvals in Codex.** In Codex's default sandbox, `.git` is read-only and the network is off. So each git write (for example `git worktree add` and `git commit`) and each network step asks the owner for approval, at least 5 clicks in each small task. When the sandbox refuses such a step, run the same command again with escalated permissions, and wait for the owner. A sandbox refusal is not a failed task. When the approval policy is `never` or the owner says no, report STATUS blocked and name the step.

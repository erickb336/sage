# A note from the user for a running lead

A note from the user for a running lead: send it with SendMessage to the lead's agent id (from its start's result), or to `lead-T<n>` when it started with that `name`, when it fits the brief. The hook refuses a message to a lead that ended: then record a new lead run and start a fresh lead with the note in its brief. When it changes the scope or the acceptance, stop the lead with TaskStop (its agent id, or `lead-T<n>` when it started with that `name`), end its own lead run (`sage run done <R> --status failed`), end each of its helper runs that still runs (`sage run done <R> --status failed`) only after its helper stopped (the board shows `helper stopped, run still open`), log the decision, and start a fresh lead with the new brief. Only you stop agents: the hook refuses a lead's TaskStop, and any agent's TaskStop of an agent. You cannot stop a helper: you do not get its agent id, and a helper started with no name field has no name. A helper of a stopped lead can still run, and it holds its slot until it stops or you end its run (or, with no stop, for about 60 minutes after its last action).

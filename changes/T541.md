- **In Codex, sage works only while its gate runs.** After each sage update, Codex runs no sage hook until you trust the hooks again, and before, nothing stopped sage mode from working without its rules. Now the gate saves a proof of each sage logbook call that it lets through, and the sage logbook server refuses every call without one, with one line: "sage's gate is not running: trust sage's hooks with /hooks in the Codex CLI (or the app's hook review), then try again." The gate also refuses a shell write to Codex's config file (the hook trust) or to the sage plugin's folder. The [Codex guide](docs/guide/codex.md#check-that-the-sage-gate-runs) has a gate check to do after each install and update. It also says what the rules see: each tool call inside a code-mode `exec` cell reaches the gate (from Codex's source), and in sage mode every app, MCP and dynamic tool other than sage's own runs with no sage rule, by your choice, also a `js` call of the desktop app's REPL, which can run shell commands that no sage hook sees (T541).

- **In Codex, sage mode refuses the `js` tool of the desktop app's REPL, and the guide says what the gate sees in code mode.** The `js` tool (`node_repl` and `cua_repl`) runs its code in its own Node process, so a shell command or a file change inside it reached no sage rule: a push to main or a merge could pass. In sage mode the gate now refuses every `js` call with one line, because it cannot read the code; outside sage mode `js` runs as before. Codex's source shows that a tool call inside a code-mode `exec` cell (`tools.exec_command`, `tools.apply_patch`, a sage logbook tool, `spawn_agent`) reaches the gate with its own name, as a direct call does, so the sage rules already apply to it. The [guide](docs/guide/codex.md#the-rules-in-codex) has the new rule and a checklist for when a rule does not run in the desktop app (T541).

- **The Codex guide says what sage's rules see in code mode and in the desktop app's `js` REPL.** Codex's source shows that each tool call inside a code-mode `exec` cell (`tools.exec_command`, `tools.apply_patch`, a sage logbook tool, `spawn_agent`) reaches sage's hook with its own name, as a direct call does, so every sage rule also holds there. A `js` call of the desktop app's REPL (`node_repl`, `cua_repl`) can run shell commands that no sage hook sees; sage mode allows it so the chief keeps its browser previews. The [guide](docs/guide/codex.md#the-rules-in-codex) gives this limit and a checklist for when a rule does not run in the desktop app (T541).

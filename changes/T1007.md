- **A task that leaves a milestone keeps its release (T1007).** Before, a task that left a milestone also left the milestone's release, with no record. Now it keeps that release as its own release, with a decision row such as `release none → 1.0`, why `T12 left milestone M5, and keeps its release`. So nothing leaves a release by itself.
  - This holds for `task <T> set milestone=none`, also for each task of a dropped milestone, and for a new `milestone propose` whose `--tasks` (or new `--pilot`) leaves a task out. The line of `task <T> set` says `keeps the release 1.0 of M5`.
  - A milestone with no release gives no release and writes no row. An ended task stays in its milestone, so its release does not change.

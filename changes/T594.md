- **A shared root for logbooks, and link commands.** `sage link --separate` starts a logbook in a new shared root (`~/.sage`), and `sage link --to <folder>` joins a checkout to one. Codex has a `link` tool. The chief runs either command only after your answer. A row in `bindings.tsv` then gives Claude and Codex the same logbook and the same cycle counts. An existing project has no row and shows no change: a new project still starts in its provider's logbook, and a link refuses a project that has a logbook, because only the move (a later pull request) takes its tasks over. The board does not show a shared logbook yet. Both hooks protect the shared root (T594).

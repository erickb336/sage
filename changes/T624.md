- **The board shows a shared project (T624, PR 5a of the shared logbook).** In Claude and in Codex, the chat board and the board page show a project with a shared logbook as one project. The board only reads. An existing project looks as before. The [board guide](docs/guide/board.md#a-shared-project-on-the-board) has each line.
  - The board reads the shared root beside the Claude and Codex roots. A new board config lists it. An existing config does not change: the server and each board command add the shared root when they read.
  - A shared logbook has no `checkout.txt`, so the board takes the checkout from its row in `bindings.tsv`, by the state tool's own owner rule. The project's name and its PR links come from that checkout.
  - Each shared card names its owning chief (`Claude · C1`), or `Unclaimed` with a dashed outline, and an open offer: it waits for a run to end, or the chief can accept now. The Who filter goes by the owning chief's provider, and an unclaimed task shows only under All.
  - A shared task's page has a Provider column in its runs, from each run's chief in `chiefs.tsv`. sage writes no new column for it.
  - Needs you asks an open Replace gate in one line. A running run of the owning chief with no change for over 24 h puts the task in Needs you: its chief may have stopped (the default of gate G103).
  - The finished tasks of the old logbooks that `sources.tsv` names show in Done with `Old · Claude · read-only` or `Old · Codex · read-only`. A moved row is hidden. The board reads only a folder with `moved.json` under a root of the row's provider, by the same rule in the chat and on the board page. A program that moved shows only in the shared logbook; an old logbook shows only its finished programs, never in Needs you. Only the move (a later PR) writes these files.
  - A task whose chief id is not in `chiefs.tsv` says so on its own page, not as a setting that the board ignores.
  - A run of a shared logbook joins its agent slot in its provider's root, so a Claude run no longer shows as "may be stuck" on the Agents page.
  - The board reads a logbook again when it changed during the read, at most 3 times. Then the note "The logbook is changing" shows over the last good read on the board page, and over the third read in the chat. When a part of the third read changed while the board read it, the note names that part in plain words: the whole logbook, a table such as `tasks.tsv`, or an artifact.
  - The chief's text names `sage board all --view chat` for "show board".
  - After you update sage in Claude and in Codex, stop a running board server with the `board --stop` command that `board --ensure` prints, then ask for the board again.

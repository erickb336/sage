- **The arena's shared rules are now in the state tool, for both providers.** An arena judge now works on its own new branch: its run needs `--branch`, the chief names that branch at `run add`, and the judge makes it from the chosen candidate's head and stops if it exists. A branch has one writer, a judge too, and a branch name in another letter case counts as the same branch. The state tool refuses a judge on a candidate's branch, a candidate on a judge's branch and two candidates on one branch, in both orders, also after a run ended. The merge check now refuses a candidate's branch, by the pull request's head branch or, with no `--head`, by the task's `branch=`. The rule reads the branch, not the commit, so a judge with no graft lands the candidate's commit from its own branch. Each candidate commits its artifact, and the chief records it with `pages`. Branches and pages stay until the owner deletes them, and worktrees go at the end of the task. Update sage before you start an arena: a judge that an older chief starts with no branch is refused, and an arena that runs during the update must finish on a new judge branch.

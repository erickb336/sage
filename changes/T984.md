- **Messages in the shapes that you approved (T984).** Each message from the chief now names its kind on its first line, for example `QUESTION`, `REPORT` or `CATCH-UP`, and follows that kind's shape: the question's table of answers with my pick, the report's table of pieces of work, the catch-up's boxes inside boxes from release to task with a state word in each box. Task and pull request numbers go only in a small Ref line at the end. The new presentation skill lists the 14 kinds and the long page, and the cold-read test that the chief runs before it sends a message ([sage's messages](docs/guide/using-sage.md#sages-messages)).
  - A message with a picture, or a message that is too long for the chat, also names its page: a file on your Mac, in the task's pages folder, that shows the whole message with each picture as an image. The image is drawn from the same text as the picture in the chat, so the two never differ. In the Claude desktop app, the path opens in the Browser pane. A design's page has a switch to today's picture.
  - The chief renders these messages with the state tool's new `message` command (the `message` tool in Codex). It refuses a message that is not in its kind's shape, a picture over 46 columns or with tree marks or a box that does not close, and task numbers in the text. Core also has these checks as functions that a later hook can run on a message that the chief writes by hand.
  - Known limits: a page loads nothing and runs only its own switch, but a page that you open can still send its own content out, for example through a link in it. A terminal with an East Asian wide setting draws the box marks two columns wide.

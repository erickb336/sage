- **Principles come from each role, not from a hook (T925).** sage has no principles hook now, in Claude Code and in Codex:
  - Each role agent starts with the principles of its role. One map in core, `ROLE_PRINCIPLES`, gives all 25 principles a role. A Claude Code agent preloads them through its agent file, and a Codex role agent gets them in its role text ([Principles](docs/guide/principles.md)).
  - The implementer, the PE, the QA and the chief get more principles than before. The PE gets 11, for example the domain model and the type system.
  - The stop check of the principles hook is gone too. Outside sage mode, no hook gives a principle: name one in your request, for example "apply prove it works".
  - **Codex: trust the sage hooks again after this update.** The other sage hooks move in the hook list, and Codex keeps each trust record by place. Type `/hooks` in the Codex CLI, trust each sage hook, then do the [gate check](docs/guide/codex.md#check-that-the-sage-gate-runs).
  - Old advice state files stay and do no harm: `~/.codex/advice/codex/` (Codex) and `agent-kit-hooks/` in the temporary folder (Claude Code). You can delete them.

- **Adopt an existing task and PR across providers.** The chief can use `task_adopt` in Codex, or `task-adopt` in the state CLI. Sage checks the project, source task, PR and live head branch. Another task's recorded run on the branch also prevents adoption. It keeps the branch, PR, source identity, spent repair rounds and configured cycle minimum. The source logbook stays unchanged. Source verdicts do not count: destination reviews and QA start fresh, with the larger source or current destination cycle requirement. An exact retry keeps the recorded adoption and current task state (T44).

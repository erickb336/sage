- **The Codex guide names the 4 approval prompts of each task.** With autopilot on in Codex, each task still asks you before 4 commands: create the task worktree, commit, push the task branch and open the pull request. Codex asks, because its `workspace-write` sandbox keeps `.git` read-only and the network off; the verified merge asks nothing. The [Codex guide](docs/guide/codex.md#the-approval-prompts-of-each-task) gives Codex's own choices, quoted from its source. It allows "don't ask again" only for the exact prefix `gh pr create`, so each task then asks 3 times. It names the prefixes never to allow, also `git worktree add`, because a git command can run the project's git hooks outside the sandbox. sage writes no Codex rule and changes nothing in your Codex config.

- **Two methods from pstack's skills, by the owner's choice of 2026-11-09 (T926).** Both come from pstack by Lauren Tan (MIT), adapted into sage's words. sage adds no new skill.
  - The encode-lessons-in-structure principle and "seal the lesson" take the method of pstack's `correct` skill. Fix a mistake that comes back at the highest level that works: the architecture, a type, a check whose error names the fix, a test, and a written rule last. Run each new check on a real past mistake and prove that it fails. Keep one rule table that pairs each standing rule with its mechanism, and drop a rule once its mistake cannot happen.
  - The code reviewer takes the method of pstack's `blast-radius` skill. Its regression check now asks what the change can break beyond its diff, and asks for the one fact that makes it safe, proved with a run of the real code. The Claude agent and the Codex role both have the new line.

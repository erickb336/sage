- **Scoped Codex role reads.** Role agents can read a task, its task board and configuration for the project in Codex's hook context. These reads do not initialize or rewrite logbook files. The interpreter and CLI require absolute paths. Task boards read and judge only the assigned logbook; the chief's merge check still covers all logbooks. Other projects, providers, command wrappers and state writes stay refused.

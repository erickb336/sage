- **Scoped Codex role reads.** Role agents can read a task, its task board and configuration for the project in Codex's hook context. These reads do not initialize or rewrite logbook files. Commands require literal arguments and absolute interpreter and CLI paths. Task boards read and judge only the assigned logbook. A passing project check gives no merge approval; the chief's merge check still covers all logbooks. Other projects, providers, command wrappers and state writes stay refused.

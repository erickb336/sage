- **The board's Ready to merge column follows the merge check.** Before, the rich board put every verified pull request in Ready to merge by its state alone, also when sage's merge check would refuse it. Now the board runs the same merge check, read-only, on the pull request's last commit. A card is in Ready to merge only when the check passes. When the check refuses (for example an open finding or a missing clean cycle), the card stays in In review and says why. When the board does not know the last commit, the card says that the merge check is not checked. The board does not see the pull request's head branch on GitHub, so it says that this part is not checked (T280).

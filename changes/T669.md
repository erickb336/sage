- **A brief points to the standing orders and does not copy them (T669).** Before, every brief copied all of a project's standing orders word for word: about 15 KB in each brief.
  - The STANDING field of a brief now holds one pointer: the orders apply in full, the agent reads them with `sage standing` before it starts, and it puts the same pointer in each helper brief. The field keeps its name, and the hook still refuses a brief without it.
  - The chief's text in Claude and in Codex, the lead's agent file and the Codex brief reference say so. The `sage` skill, the `standing` tool of the Codex server and the dictionary no longer say that a brief copies the orders.
  - A new logbook's standing orders start with "Every agent reads these orders before it starts; a brief points to them." An existing logbook keeps its first line until the chief edits it, and a move drops the old line and the new line alike.

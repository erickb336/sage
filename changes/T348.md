- **The board keeps up with a write that macOS does not report.** On macOS each new file watch restarts the file event stream, and a write in that time gave no event, so the board could stay out of date until the next change. On a busy Mac this also failed the board server tests with "no matching board event". The board now reads the logbooks five times in the 15 seconds after a new watch, not once. You do not need to do anything.

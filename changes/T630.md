- **The board reads old logbooks and `sources.tsv` more safely (T630, before the move of existing projects).** The [board guide](docs/guide/board.md#a-shared-project-on-the-board) has the lines.
  - A `sources.tsv` row that the board does not read is now a line under Logbook notes, not an incomplete source: the board page stays live for every project. A folder that the board cannot search, or a folder name that is too long, refuses only its own row. Only the provider words `claude` and `codex` read.
  - An open gate on a finished old task is not in Needs you. An open row that a move did not finish says that it is open, not finished.
  - The task view of a shared logbook in a session finds an old finished task by its id.
  - A shared root that is a link or a file is one quiet note for a project that is not shared, not a lasting incomplete source.
  - A board source of another id at the shared root's path reads as the shared root.
  - A run's checkout folder name on the task page loses bidi and control characters. A folder past the 64 that the board checks says `· not checked`. A checkout that is now a plain file or an empty folder is gone: the review refuses with the run's ID, and readiness gives `readiness-checkout`.

- **Codex keeps each arena report, and a candidate's report names the commit of its own branch.** The report check now keeps the exact report of an implementer and of an arena judge, so `report_compare` finds them. Before, it returned `missing`. No verdict depends on these reports. A writer run (an implementer, an arena judge or a designer) gets the head of its own branch at its stop, also when it committed during the run. A missing branch gives no commit, and the check never uses the task's branch instead. A review or QA run reads the branch of its task, and that branch must not move during the run, or the run gets no commit.

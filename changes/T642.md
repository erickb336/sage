- **A new project starts in a shared logbook (T642, PR 7c of the shared logbook).** `sage init` of a project with no logbook links it with `sage link --separate` when every plugin is ready, and says so: "<checkout> now uses the shared logbook <folder>. Every plugin is ready, so the project starts there."
  - Ready: each provider root has its provider's name, `plugins.tsv` has each provider at contract 2 or recorded as unused, and neither provider root has a logbook of this repository, also a clone's (rule 2 wins, so that one move later takes them together).
  - Otherwise `init` makes a legacy logbook, as before, with no new text. An explicit `SAGE_HOME` stands for every root, so a scratch run keeps a legacy logbook. A `plugins.tsv` that sage cannot read is not ready.
  - A checkout with the first commit of a shared logbook still gets the link prompt, and a repository with no commit yet starts shared: its row gets the first commit at a later write.
  - Only the move gate records a provider as unused.

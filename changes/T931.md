- **Stash, process and board password rules in Codex (T931).** These rules now live in core, and the Claude sage hook and the Codex gate both call them, with the same reason in both:
  - An agent runs no `git stash`, in any form, and no real `ps`, `pgrep`, `kill`, `pkill`, `launchctl` or other process program. A fake in the temp folder still runs. The chief is not held: the main session in Claude Code, the main thread in Codex.
  - No one sets the board password or reads, copies, replaces or searches the board config, in any mode. In Codex this covers shell commands and patches.
  - The process reason no longer names a Claude tool: it says to run a server as a background task and stop that task.
  - The keep matrix plays each rule as a Codex agent too ([The rules in Codex](docs/guide/codex.md#the-rules-in-codex)).

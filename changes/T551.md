- **The Codex gate now lets a lead start its own team.** A child named `sage_lead_t<n>` may start implementer, code reviewer, security reviewer, UX reviewer and QA agents with the same task number. The gate refuses any other spawn by a lead, with a line that names the rule. Under a lead, the last sage name of the agent path decides the edit rule: an implementer edits, a reviewer or QA stays read-only, and the lead itself edits nothing. A path with any other sage name above the last one is refused. Sends stay refused. The chief still starts no lead in Codex, so nothing changes for you yet.

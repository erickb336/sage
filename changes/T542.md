- **Clearer next steps for the change log.** The error for a line written by hand in `CHANGELOG.md` now gives one step for each kind of branch. On a task branch, put the text in `changes/<task>.md` and undo the edit with the real merge base. On a change-log branch, undo the edit from `origin/main`, run `npm run changelog`, and put the text in a task pull request. The refusal of a task diff that edits `CHANGELOG.md` puts `git fetch origin main` before the `git checkout`. [CONTRIBUTING.md](CONTRIBUTING.md) has one part for an implementer and one for the chief, and says to merge main into a stale change-log branch first. The chief's instructions name the change-log pull request after task pull requests merge (T542).

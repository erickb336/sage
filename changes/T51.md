- **Verify installed Codex package files.** The chief and assigned roles can run `sage.mjs verify-install --commit <full40hexSHA> --project <absolute assigned project>`. It compares tracked package files with that commit, reports counts and relative paths, and writes nothing. Project identity and object reads ignore inherited Git selectors and use trusted system Git locations independently of `PATH`. Missing local objects fail without remote access or repository transport helpers. Regular-file entries must reference actual blobs, not tags that point to matching bytes. This check does not establish runtime trust or release readiness. Installation and configuration writes remain blocked.

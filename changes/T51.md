- **Verify installed Codex package files.** The chief and assigned roles can run `sage.mjs verify-install --commit <full40hexSHA> --project <absolute assigned project>`. It compares tracked package files with that commit, reports counts and relative paths, and writes nothing. Project identity and object reads ignore inherited Git selectors. Missing local objects fail without remote access or repository transport helpers. This check does not establish runtime trust or release readiness.

- **Codex autopilot, inactive parts.** This adds the first half of the Codex autopilot (T663). The owner sees no change until T677 turns it on: the Codex gate still refuses every merge. The Codex plugin has three new parts:
  - **The owner record reader** reads the owner's autopilot switch from Codex's session record, with core's own mode rules. It refuses a record that it cannot prove, for example from an unknown Codex version.
  - **The start marks:** at each startup, resume, clear or fork, a hook saves where the session starts in the record. So an on phrase from before a resume never counts.
  - **The merge command** (`skills/sage/merge.mjs`) merges only with a one-time merge permit for its exact call, while the owner's switch is on. No hook saves a merge permit yet, so it refuses every merge.

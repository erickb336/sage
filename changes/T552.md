- **A Codex lead can now record its own task.** A child of the chief named `sage_lead_t<n>`, while its task's lead run runs, may use the sage tools for runs, findings, verdicts, rounds, pages and briefs of its own task, and move that task through a cycle. Each call on another task is refused with a line that names the rule. The rules follow the Claude lead's: a lead adds only runs of its team, dismisses only a low finding, moves no finding to another task, leaves a checks verdict to the chief, repairs through a round, and closes each fix of the round before it goes back to reviewing. A lead whose lead run ended, or whose task is held or finished, records nothing and starts no agent. A reviewer or QA agent under a lead now has its report kept, so that it can back a verdict. The gate's proof of a call now carries the caller, and the sage server applies the caller's rule itself. Only the session's main thread passes as the chief, whatever name a child has. The chief still starts no lead in Codex, so nothing changes for you yet.

- **A checkout path that holds "board" or "config" no longer trips the board password rule (T632).** When the Claude hook could not read a command line (an open quote, for example), it refused the line if its text held "board" or "config" anywhere. So a line in a checkout such as `.../board-wt/...` was refused as if it named the board config, and a test of the hook failed only at such a path.
  - Now the hook reads such a line as code from an unknown folder, with the same path test as for `node -e` code. It refuses the line when a word can stand for the board config or a folder above it (`board.json`, `~/.config`, `.config`, `sage-b*`), and lets other paths pass.
  - The board password rule table has new rows for both cases.

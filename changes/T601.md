- **A candidate run stays off another task's branch.** `run add` now refuses a candidate run on a branch that another task names by its `branch=`, or where a writer run of another task worked, in any letter case, also after that run ended. The refusal names that task and says to use another branch. Before, the run went in, and its row then barred the other task from its own branch for good. The Claude and Codex paths share the rule. A review run claims no branch, and a build on a branch that two tasks share works as before. A candidate run stays off a shared branch too, because a candidate's branch never lands.

- **Reviewers and QA can write and run their probes in their own scratch folder.** Before, the hook refused a fake script with `"$*"`, a heredoc proof with braces, `node -e` with `{spawnSync}` and `$?` as "near the logbook", also in the agent's own scratch folder. Now a run's own scratch subfolder, `<scratchpad>/<run id>`, takes these writes and runs: a heredoc, `echo` or `printf` into it, `mkdir` and `chmod` on it, `node` on a script in it, and `node -e` code whose paths are in it. The text of a file that a command only writes is data, also words such as `kill` or `verdict`. The hook finds the folder from facts that the agent cannot set, and refuses as before when it cannot find it. A write to another run's folder, the repository or the logbook, through a link, or with `..`, stays refused.

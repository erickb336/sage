A legacy logbook does not change: it gets no column. The [board guide](docs/guide/board.md#a-shared-project-on-the-board) has the lines.
  - A shared task's page shows `checkout <folder>` under each run's role: the folder name only, never its path. The chat text adds ` · checkout <folder>` after the role. A run from before this change shows no line.
  - When that folder is not on this Mac now, the run shows `· gone`. While the task is active, one note under the runs says that its next review step stops until the folder is back.
  - In Codex, a review reads the task branch in the checkout of the branch's newest writer run (implementer, designer or arena judge), so a second clone that `sage link --to` linked reads the right commit. That checkout must be a row of `bindings.tsv` for the logbook. A gone checkout refuses with the run's ID and changes nothing; a move to verified gives the code `readiness-checkout`. Start the run again from a live checkout.

- **The Codex report check now refuses each report that the Claude stop gate refuses.** The reader was already in core, and T560 connected it for a review child with a run in its task name. Two differences stayed. A review or QA child with no run in its name, or with another letter case, got the field check only: a report with a high finding that the reader cannot read went through. Codex also had its own field rule, so a field in a list item, on an indented line or in a code block counted. Now the reader follows the role in the task name, and the one field rule (`missingFields`) moved from the Claude hook into core, in place of the Codex rule. The Codex guide no longer says that the check does not read a review's findings (T461).

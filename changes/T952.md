- **One agent cap for both providers (T952).** The state tool refuses `run add` while the project already has its agent cap of running runs (`max_agents`, 10 by default, or `cap.<project>`), of every role, in Claude Code and in Codex. The refusal names the running runs. A run that ended holds no place, so the chief ends a stuck run to free one.
  - In Codex, the start status warns when Codex's thread limit is below the project's agent cap, and names the line to change in your Codex config. It reads `features.multi_agent_v2.max_concurrent_threads_per_session` first, because that value wins and counts the chief's own thread, then `agents.max_concurrent_threads_per_session`, then Codex's default of 4 threads.
  - The Codex guide no longer lists "a third helper fails, and no agent cap" as a known limit. Its What you need section explains the thread setting.
  - Claude's hook keeps its count of live agents, against the same cap value.

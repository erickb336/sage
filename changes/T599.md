- **A moved or re-cloned checkout gets a true next step (T599).** A checkout with no row and a shared logbook's first commit no longer starts a logbook.
  - Each command and `init` refuse, name the logbook, and offer `sage link --to <folder>` or `sage link --separate`. Before, `init` made a logbook that the link then refused.
  - A row of a checkout that left the disk no longer refuses the only live checkout. It can still keep out a checkout with other first commits.
  - A `--to` with a wrong folder lists the logbooks in the refusal, so a Codex chief needs no read of `projects.tsv`.
  - A command from a folder that is gone says so and names the next step.

- **CI runs the tests in 4 parts at the same time.** The check workflow runs `npm test` in 4 parallel jobs, and `npm run check` and the browser tests in a fifth job. `node --test` sorts the test files by path and gives each file to exactly one part. The job named `check`, which branch protection requires, waits for all of them and passes only when each one passed. To run one part on your machine, set `TEST_SHARD`, for example `TEST_SHARD=2/4 npm test`; without it, `npm test` runs every file (T912).

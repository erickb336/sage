- **In sage mode, no push reaches the default branch, whatever the remote's name.** The push rule of the Claude hook and the Codex gate (one rule in core) now reads the checkout's remotes, git's settings and `refs/remotes/<remote>/HEAD`. A push to a remote with any name passes for the task's branch, so a project whose one remote is `github` works. A push to main, master or the remote's default branch is refused in every form: `HEAD:main`, `:main`, `refs/heads/main`, `--all`, `--mirror`, a URL, `-C`, `git -c`. When the hook cannot read the default branch, only a task's branch passes. A `remote.<name>.push` setting, or `push.default` upstream with another upstream, refuses the push, because git would send the branch to another name. A push line may run only `cd`, `git add`, `commit`, `status`, `log`, `diff`, `fetch`, `gh` and `echo` beside the push, so that no command changes those settings before the push runs.

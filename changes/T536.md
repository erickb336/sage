- **In sage mode, no push reaches the default branch, whatever the remote's name.** The push rule of the Claude hook and the Codex gate (one rule in core) reads the checkout's remotes and git's settings, and asks GitHub for the repository's default branch with a GET; when GitHub does not answer, the push is refused. A push to a remote with any name passes for the task's branch, so a project whose one remote is `github` works. A push to main, master or the default branch is refused in every form: `HEAD:main`, `:main`, `refs/heads/main`, `--all`, `--mirror`, a URL, `-C`, `git -c`, a symbolic branch ref, and the settings `remote.<name>.push`, `remote.<name>.mirror`, `url.<base>.insteadOf` and `push.default` upstream. Beside the push, a line may only run `cd <dir>` (no option, and no `||` or `&` in the line), `pwd`, `git add`, `commit`, `status`, `log`, `diff`, `show`, `fetch` or `rev-parse`, `gh`, `echo`, `printf`, `true`, `cat`, `head`, `tail`, `grep` or `wc`, and writes no file (`tee` or `>` is refused) and sets no upstream (`--set-upstream`, fetch's `-u`). `git subtree push`, a git subcommand that is not a known built-in (`send-pack`, an alias), a setting of `core.hooksPath` or `core.fsmonitor` (by `git config`, `git -c`, `--config-env`, `GIT_CONFIG_KEY_<n>` or `GIT_CONFIG_PARAMETERS`, also inside `sh -c`), a write under `.git` (also by git's own `--prefix`, `--output` or `-o`), `gh repo sync`, `gh repo edit --default-branch` and a `gh api` write of `default_branch` are refused too, also with a doubled or trailing slash in the route. A GraphQL `createCommitOnBranch` is checked against the default branch of the repository that its `repositoryNameWithOwner` names. A read of those settings (`git config get`, `--get`, `--list`), and a commit message (also `git -C <dir> commit`), `echo` or search (`grep`, `git grep`, `rg`) that names them, pass, and so does a Bash description that starts with `git <word>`. A remote URL with `?`, `#` or `%` before its `@` is not read as GitHub. These text rules cannot be complete; GitHub branch protection is the real lock.

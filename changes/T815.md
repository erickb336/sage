- **The hooks judge the programs that a command line runs, not its text (T815, part 1: core and the Claude hook).** By the owner's decision of 2026-11-07, the shell-text rules are gone; they caused most agent refusals, nearly all of them false alarms. On the refusals that agents met since 2026-11-07 22:00, 327 of 346 (95%) now pass, and each one that stays refused meets a rule that the cut keeps.
  - A merge is a run of `gh pr merge`, or of `gh api`, `curl` or `wget` with a pull request's merge path or a GraphQL merge mutation, also inside `sh -c`, `eval`, `xargs`, `find -exec`, `env` or `$( )`. Merge or push text in a commit message, a pull request body, an echo or a tool call's description passes.
  - A `git push` that another program runs is refused: a push runs only as a command of its own, in the push form. The merge form, the merge check, the push form, the owner's push rule, the known git subcommands and the hooks path and `.git` rules are unchanged.
  - An agent's or the chief's shell write is refused when a literal path of a written word, a `key=value` or `--option=value` value, or a redirection target is in the sage root or the shared root, also through a link, after a `cd` or from `~`. A pattern counts by its literal part. A logbook file's name elsewhere, `$?`, braces and scratch work pass; the scratch exemption is gone with the rule that it eased.
  - An agent runs the state tool's read commands also in a pipe or a chain, and any program may read its files. It runs `gh pr create`, `view`, `comment`, `edit`, `checks`, `diff`, `list` and `status`, `gh issue view` and `list`, `gh run view`, `list` and `watch`, `gh repo view`, and `gh api` with GET, by gh's own words, with any command before or after them.
  - A variable, a substitution or a pattern in a program word or a path, a gh alias or a renamed copy, code or a script, text piped into a shell, and a folder known only at run time are documented limits of the hook; the sandbox is the full guard ([Rules held in code](docs/design/rules-in-code.md#the-limits-of-the-hook)). The Codex gate takes the shared merge rule and push readers now; its own shell-text rules go in part 2 (T903).

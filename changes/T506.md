- **The Codex chief ends each run on the first try.** Codex gives no token count for an agent, so the state tool ends such a run only with `usage` unavailable, `usage-source`, `usage-evidence` and `report`, and no `tokens`. The chief learned these fields only from a refusal, and until then the open runs held the merge. Now the `run_done` tool's description and the chief's dispatch step name each field and give an example call. The Codex chief cannot write the pages folder from its sandbox, so the `pages` tool now saves a run's report itself: give it the task, the run and the report as `text`, and it saves `<R>-report.md` in the task's pages folder, records it, and prints the path for `run_done`. It refuses an empty report and a run of another task, and it never replaces a saved report. The CLI form is `sage pages <T> record --run <R> --text <report>`. The rule of `run done` did not change.

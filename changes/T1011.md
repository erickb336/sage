- **In Codex, the shape note is about the chief's last message only (T1011).** Before, when the chief's message missed its kind's shape and a later message fitted, with no message of yours between them, the chief still got the note about the older message. Now each end of the chief's turn removes the older note first, as in Claude Code. A later message that fits, a message that names no kind and a turn with no message all leave no note. Each miss is still counted in `message-misses.jsonl`.
  - A note file that sage cannot read is now removed at your next message, so sage does not try to read it again at each message.
  - You do not need to trust the Codex hooks again: this change is in sage's files only, not in the hook entries of your Codex hooks file, so Codex keeps them trusted.

- **Change-log steps that work as written.** When `npm run changelog` stops on a line written by hand, each step that it gives starts with `git fetch origin main`, so the step works also when `origin/main` is stale or missing. A folder with no `.git` inside another repository no longer gets the merge base of that repository. The chief's steps in [CONTRIBUTING.md](CONTRIBUTING.md) now give the commands: `git fetch origin main`, `git switch -c <branch> origin/main` and `git merge origin/main` (T559).

- **The PR script and the Claude hook read a shared task's branch in its writer's clone (T634, PR 6a of the shared logbook).** In a shared logbook with two clones that `sage link --to` linked, the branch lives in the checkout of the branch's newest writer run (implementer, designer or arena judge), not always in the chief's folder. A legacy logbook does not change.
  - `sage-pr` reads the origin of that checkout, so a chief in clone B pushes and opens the pull request on the repository of clone A, where the implementer worked.
  - One logbook has one repository: when that checkout's origin is another GitHub repository than the origin of the logbook's owner checkout, `sage-pr` refuses (exit 1), names the two repositories and pushes nothing.
  - When that checkout is gone, `sage-pr` refuses (exit 1) with the run's ID, pushes nothing and changes no table. Start the run again from a live checkout.
  - A writer run from before T625 has no checkout, so `sage-pr` reads the chief's own folder, as before.
  - The Claude hook reads a task branch's tip in the same checkout, for example the commit that a review's report keeps. A gone checkout gives no commit, so that report backs no verdict.

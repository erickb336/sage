- **Codex autopilot is on.** In Codex 0.164 to 0.166, `autopilot on` now turns autopilot on, as in Claude Code (T677). After a task's clean cycles and a passing merge check, the chief merges with sage's merge command, with no prompt for the merge. Press Esc to stop a merge now; `autopilot off` sent with Enter stops merges from Codex's next step. The parts:
  - **The hook's admission:** it admits the merge command only from the main thread, with autopilot on in the mode file and in Codex's own record of the session, then saves a one-time permit.
  - **Every off counts:** an off phrase counts from any message of Codex's record, also with an image or with odd metadata, and nothing blocks it.
  - **Fail closed:** a start note of an earlier Codex process, a newer Codex, a merge call that is not in the record, or a `gh` in a folder that the sandbox can write stops the merge.
  - **Permits:** they are in the Codex home where the plugin is installed, so a caller cannot point the command at a permit of its own.
  - **The desktop app:** an on phrase that you type in the app counts, as in the terminal UI. An on phrase from a message that the app queued, or from an automation, counts for nothing.
  - **gh:** sage runs gh by the name `gh`, so a gh from snap or mise works. gh, and the git that it starts, come only from folders that the sandbox cannot write. Of the merge's network access, the hook allows only GitHub's API itself.
  - **The texts:** the help, the guide and the README say what Esc, Enter and Tab do to a merge, that autopilot stays on after Esc, and which Codex, `node` and `gh` a merge needs.

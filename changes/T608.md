- **Each default root now reads the HOME of the env it gets.** A caller that gives the state tool or the Codex mode hook an env with a scratch HOME, and no SAGE_HOME, now stays under that HOME. Before, these roots read the process's own home folder, so such a run could write to the real sage root. Sessions and commands do not change: their env is the process's env, so they find the same root as before.

- **After a takeover, the former chief and its agents no longer push to the task's branch (T822).** In a shared logbook, both hooks (Claude and Codex) now refuse a `git push` of a branch that a live task of another chief uses, also a push of its agents. `sage-pr create`, which pushes the task's branch, follows the same rule.
  - A task uses a branch by its `branch=` or by a run of it on that branch, as the merge check reads it. A branch that no task uses passes. A merged, concluded or abandoned task bars nothing.
  - The refusal names the task, its owning chief and the takeover gate to ask the owner for the task (`gate replace <T> --to C<n>` in Claude, the `gate_replace` tool in Codex).
  - The merge check and the push rule use one owner test of the state tool. A legacy logbook has no chiefs, so its pushes work as before.

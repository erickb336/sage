- **The Codex guide tells you to choose "Yes, and don't ask again" at the approval prompts.** On autopilot, choose it the first time each of the 4 prompts of a task comes (create the worktree, commit, send the branch, open the pull request). After that, Codex asks no more for that kind of step, so autopilot does not stall. Choose "Yes, proceed" to be asked each time. The trade-off: the saved rule lets a later command that starts the same way run with no prompt and outside Codex's sandbox, from any Codex thread, and `git commit` runs the project's own git hooks; sage's hook still refuses a push to main and a merge that is not ready. The [guide](docs/guide/codex.md#the-approval-prompts-of-each-task) names the same choice for the network prompt, and says how to remove a saved rule. Before, it said never to choose "don't ask again" (T507).

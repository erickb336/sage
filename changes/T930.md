- **Programs and settings work in Codex (T930).** The Codex `sage` MCP server has two new tools, so that the Codex chief does what the Claude chief does with the state tool:
  - `program_propose` proposes a program and opens its breakdown gate, also again after your change answer or for a new pilot. A task joins or leaves a program with `task_set` and `program=`, as before.
  - `config` sets the cycle counts, `max_leads` and the other counts for all projects, and the project's board name and archive. The chief uses it only when you ask.
  - Only the chief calls them: a lead and a role agent get a refusal. Each tool gives the same line as the Claude state tool.
  - The Codex guide's tables name both tools and programs ([The logbook tools](docs/guide/codex.md#the-logbook-tools)).

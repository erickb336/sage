- **In Claude Code, an investigation runs on its own agents: `sage:investigate` and `sage:evidence-review` (T932).** Before, the chief started them as general agents, with no read-only rule, no report reader and no principles.
  - Each agent starts with the principles of its role from core's `ROLE_PRINCIPLES`, and with the same role text as in Codex: the two texts moved from the Codex skill into core.
  - In sage mode, the hook refuses their writes to the project, from the shell or a file tool. The investigate agent may write its research page in the task's pages folder (the folder that `sage pages <T>` prints) and files in its scratch folder. The evidence review is read-only.
  - The hook checks their briefs and reports like those of the other agents. It reads the evidence review's report as it reads a review's, and keeps it for its run when the brief starts with the run line.
  - In Codex, `role.mjs investigate` and `role.mjs evidence-review` print the same text as before, except one word: "the report format included below", as for the other roles.

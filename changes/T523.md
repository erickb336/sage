- **A lead's wait no longer returns at once in a loop.** When a review or QA helper stopped with a report that the hook cannot read and another helper still ran, the lead's wait command returned at once each time, and the lead could not end that run: only the sage does. Now the wait leaves out such a run: it names the run once, with what to do, and waits for the helpers that still run, up to its 9 minutes. When no helper runs, it returns with the list of these runs. The lead names each one in its report as a gap, and ends blocked only when no helper of its own runs. The text of the hook that blocks a lead's stop now says when the wait returns.

- **In Claude Code, a reviewer or QA agent no longer changes files from the shell (T933).** In sage mode, the hook refuses a shell write form, such as `sed -i`, a redirection to a file, `tee`, `cp`, `mv` or `rm`, from the code reviewer, the security reviewer, the UX reviewer, QA, the PE and the lead. The agent files already took away their file tools. The rule comes from core (`roleEditDenied` and `commandWrites`), as in the Codex gate. A redirection into the temp folder, outside the project, still passes, so that these agents keep their output and probes in their scratch folder. Test runs and read commands pass. The implementer, the designer and the arena judge are not affected.
  - `commandWrites` in core takes an optional list of scratch folders, where a redirection does not count.
  - A write that a variable, a pattern or a script's own code hides is a limit of the hook.

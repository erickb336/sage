- **Inactive Codex trigger observation.** A separate command checks bounded synthetic root-turn records and returns a fixed classification or refusal. It checks diagnostic identities, preceding terminals and supported record discriminators. Message contents remain opaque under the revised T90 diagnostic contract. It enables no hook or mode change. The [Codex guide](docs/guide/codex.md#inactive-trigger-observation) gives the sample command and its limits.

- **The lead limit is now a config key.** `max_leads` sets the most running leads of a project, and its default is 5 (it was a fixed 3). Ask the chief in the chat, and it runs `sage config max_leads=<n>`. The state tool and the hook read the same value. A lower value ends no lead: it only refuses the next one. The agent caps still apply to each lead.

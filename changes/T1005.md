- **In Codex, a note when the chief's message misses its shape (T1005).** When a message of the chief names its kind on its first line, for example `QUESTION`, and misses the shape of that kind, the chief gets a note with your next message. The note names the kind and each problem, for example a missing "Needed by" part or a task number outside the Ref line. Nothing is blocked, and you see no line. A message that names no kind is not checked. Each miss adds one line (the time, the kind and the names of the problems, never the message's text) to `message-misses.jsonl` in the Codex hooks' folder, so that sage can count the misses.
  - The check runs on Codex's Stop event: a new, eighth entry in your Codex hooks file. After you update sage, the start status says that 1 sage hook entry is missing: say yes, and the chief runs `hooks install` (or run it yourself). Then trust the new hook once with `/hooks` in the Codex CLI. Until you trust it, Codex does not run it, and the start status says that 1 sage hook is not trusted.

- **A helper's slot stays held until the helper really stops.** When the sage ends a helper's run while the helper still runs, the run ends in the logbook and the lead goes on, but the helper's slot stays held, so the agent cap counts the helper. The helper's own stop frees the slot. Its report then counts in the lead's check for unrecorded findings, and the ended run keeps its status. If no stop comes, the one-hour lease frees the slot. So after a restart, the slot of a helper that died holds for up to an hour after the sage's `run done`. Before, `run done` freed the slot at once, and the late report was lost.

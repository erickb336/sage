- **A pinned sage marketplace in Codex gets a warning and a fix (T971).** When your Codex config pins the sage marketplace to one commit (a `ref = "<commit>"` line under `[marketplaces.sage]`), `codex plugin marketplace upgrade sage` fetches the same commit, and `codex plugin add sage@sage` keeps the old copy. The start status and `hooks status` now say so, and give the 3 commands that end the pin: `codex plugin marketplace remove sage`, then `codex plugin marketplace add https://github.com/erickb336/sage-stack.git`, then `codex plugin add sage@sage`. A `ref` that names a branch gets no warning.
  - An install from before T957 has no `hooks` command, so its `hooks install` stops with `unknown command "hooks"`. The Codex guide ([Update and remove](docs/guide/codex.md#update-and-remove)) and the README now give the same 3 commands as the first step for such an install.

- **A stopped write no longer needs the chief that started it.** The next writer of a logbook, from Claude or Codex, finishes or undoes a write that stopped half way, and then runs its own command. A write with a receipt rolls forward. A write with no receipt restores its "before" tables. A task update that the journal rejects now writes no receipt, so a retry gets a fresh answer; an old rejected receipt still reads as rejected. Codex adds one journal event, `void`, and one settle step that runs before decide, prepare, assign, finish and a child's terminal check. A write that cannot finish stops only its own project. The merge check settles its own project and skips another logbook that holds a saved change, with a note, unless that logbook names the commit. A retry of a committed request now always reads `already-created`, `already-accepted`, `already-finished` or `task-update-history`, because any writer may have settled it. The `old-owner` and `pending-request` errors are gone (T578).

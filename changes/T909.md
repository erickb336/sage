- **The hooks guard the common forms only: the checks that existed only to stop a deliberate trick are gone, in the Claude hook, the Codex gate and core (T909, guard cleanup part 1).** By the owner's decision of 2026-11-08 (standing order 70), a disguised form is a documented limit; GitHub's protection of main, the merge check, the sandbox and the owner's phrases are the guards against tricks.
  - Still refused, in both hooks: every common `gh pr merge` form that is not the one merge form; a push with `--force`, `+ref`, main or master, `--mirror`, `--all`, the default branch that GitHub names, no branch, or from a checkout on the default branch; a push of a branch that another chief owns; `git subtree push`, `gh repo sync` and `gh repo edit --default-branch`; a shell write by a literal path into the logbook roots; the agent rules for the state tool, gh, `git stash` and the process programs; and the board rules.
  - Now limits, so they pass: a merge or a branch write through GitHub's API (`gh api`, GraphQL, `curl`, `wget`); a wrapper program that the reader does not know (`arch -arm64`, `op run --`); a git alias or another unknown git subcommand; a pattern or an option order in a program word or in gh's command words; a git setting that redirects a push (`remote.<name>.push`, `remote.<name>.mirror`, `url.<base>.insteadOf`, `push.default` upstream), a symbolic branch and a local `HEAD` that disagrees with GitHub; code that loads the state tool (`node -e`, `-r`, `--import`); a path through a link; PowerShell's own syntax (`Start-Process`, backtick escapes); and a severity word in look-alike letters of another script.
  - A push beside other commands in the same line passes, and each push that the reader finds, also inside `sh -c` or `eval`, meets the push form.
  - Q1 (a): the `.git` folder and `core.hooksPath` rule is gone in both hooks, because it also refused honest setups such as husky.
  - The Codex gate no longer refuses a command that only reads the Codex sage folder, the shared root or the Codex sessions folder; it refuses shell writes and patches into the sage folder and the shared root, as the Claude hook does. An agent's gh in sage mode meets core's agent list (`AGENT_GH`), as in Claude Code; the chief's gh meets the merge and push rules. Codex is known by its name; a renamed copy is a limit.
  - A lead closes a fix finding of its round while repairing, also before a new commit (F-T289-6 is gone); the next review cycle checks the repair.
  - F-T903-7: `find ~ -name '*.tmp' -delete` and `chmod -R u+w ~` pass; a `find` or `chmod -R` counts only when a word names a path in a root. F-T903-10: `rm` of a project link to the shared root removes the link and passes.

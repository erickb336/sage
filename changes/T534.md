- **In Codex, "autopilot on" works after a normal install, and a pull request lands the same way as in Claude Code.** Send `sage mode`, then `autopilot on`, each alone; nothing else is needed. The chief lands a verified pull request with `gh pr merge <n> --squash --delete-branch --match-head-commit <sha>`, and the sage gate allows it only with autopilot on and a passing merge check. The gate reads the mode from its own record of your typed phrases, with the session that Codex gives it, so a mode file or a session id that an agent makes does not count. Before, the skill sent the chief to a separate merge helper that needed evidence files that a chief could not make, so autopilot stayed off; that helper is gone The gate now also refuses a message from any thread to the session's main thread, because Codex counts it as your own typed message, and in sage mode a `gh` command whose first word is an alias or an extension ([guide](docs/guide/codex.md#turn-on-sage-mode)) (T534).

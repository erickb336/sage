- **In Codex, "autopilot on" works after a normal install.** Before, the merge helper needed a record of evidence for the installed helper, and a chief could not make it, so autopilot stayed off. Now the reviewed release is the check: the build writes the sha256 of the helper and of each file that it imports, and the helper compares the installed files with them before autopilot and before each merge. A changed or missing file still refuses, with a reason that says to reinstall sage. The helper also finds the project's GitHub remote by its URL, not by the name `origin`: exactly one remote must point to the pull request's repository. Every other merge rule stays ([guide](docs/guide/codex.md#turn-on-sage-mode)) (T534).

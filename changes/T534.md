- **In Codex, "autopilot on" works after a normal install.** Send `sage mode`, then `autopilot on`, each alone; nothing else is needed. Before, the merge helper kept its own mode, from an owner record with an evidence file, and needed a record of evidence for the installed helper; a chief could not make it, so autopilot stayed off. Now Codex has one autopilot path: the sage hook's record of your typed phrases, which the merge helper reads, and a phrase in a tool output or an agent's report does not count. The reviewed release is the check of the helper: the build writes the sha256 of the helper and of each file that it imports, and the helper compares the installed files with them before each merge. A changed or missing file still refuses, with a reason that says to reinstall sage. The helper also finds the project's GitHub remote by its URL, not by the name `origin`: exactly one remote must point to the pull request's repository. Every other merge rule stays ([guide](docs/guide/codex.md#turn-on-sage-mode)) (T534).

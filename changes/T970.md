- **The gap rule also holds a lead's round, and a late report holds the lead in every logbook (T970).** This polishes the gap rule of T956.
  - A lead's `round` waits for the rows of its helpers' findings, as its state move does, because a round takes its fix keys from those rows.
  - The refusal names `finding add` and its fields (task, source, severity, run, class and summary), so a Claude lead and a Codex lead (`finding_add`) each read their own form.
  - The chief text says that a row of the run counts whoever records it, the chief too, but only with `--run`.
  - Decision: a run that ended as blocked or failed keeps its late report in a legacy logbook too, as in a shared one. Reason: one rule for every logbook is fewer rules, and the late report's findings then hold the lead, so a normal lead cannot go on past them because the chief ended the run first. `task <T>` prints the path of such a report in every logbook. A run that ended as done still keeps no late report.
  - Decision: the findings of a kept report of a blocked or failed run still hold the lead. Reason: the run's status says how the run ended, not whether its findings are true, and a rule that skips such runs adds a case. A row of the run frees the lead, and the chief can still dismiss the finding.

- **The owner test of `sage-pr create` runs first again, and a legacy push reads no logbook (T901).** Two repairs of the push rule of T822:
  - In a shared logbook, the Claude hook now checks that the session's chief owns the task before it reads the task's branch. So a damaged table, such as an empty `findings.tsv`, no longer lets another chief's `sage-pr create` pass. When the branch's read fails, `sage-pr create` refuses and names the damaged file.
  - In a legacy logbook, a `git push` no longer reads the logbook in either hook (Claude or Codex). So a damaged table no longer refuses a push that worked before T822.

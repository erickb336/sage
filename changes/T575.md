- **Adoption works when task numbers overlap across providers.** A branch such as `codex/t95-init-lock-test` no longer counts as claimed by an unrelated destination T95. Only a recorded claim refuses adoption: a task's PR history, its recorded branch or a run on that branch. After adoption, the merge check, `sage-pr` and the lead's branch rule treat the adopted branch as the adopted task's own. Source claims, provenance, spent rounds and fresh destination reviews do not change (T575).

- **A warning when autopilot runs without branch protection.** When autopilot turns on, sage reads once per session (one read-only `gh` check) whether the default branch of the repository requires a pull request, through a ruleset or a branch protection rule. If not, the confirmation adds one line with the steps to turn it on. Autopilot still runs and lands as before, and a failed read says "could not check" and blocks nothing. Claude Code and Codex both do this (T547).

- **A warning when autopilot runs without branch protection.** When autopilot turns on, sage reads once per session (read-only `gh` checks, all inside one 5 second limit) whether the default branch of the repository requires a pull request, through a ruleset or a branch protection rule. If not, the confirmation adds one line with the steps to turn it on. A private repository on a free GitHub plan gets a different line: GitHub offers no protection there, so the line says to make the repository public or upgrade to GitHub Pro. Autopilot still runs and lands as before, and a failed or slow read says "could not check" and blocks nothing. Claude Code and Codex both do this (T547).
